## 14:19:24–14:20:35 — CHANGE: `out/` copied to backup (71 s)

```powershell
robocopy $src $dst /E /COPY:DAT /DCOPY:T /R:2 /W:2 /MT:16 /NP /LOG:...\robocopy-out.log
```

Flag choices, deliberate: `/E` not `/MIR` (mirror deletes at the destination —
wrong risk profile for a first backup); `/COPY:DAT` not `/COPYALL` (the latter
copies audit ACLs and fails without elevation); `/R:2 /W:2` because the default
is one million retries and would hang forever on a single locked file.

Result — full log at `_meta\robocopy-out.log`:

```
             Total    Copied   Skipped  Mismatch    FAILED    Extras
   Dirs :       10        10         0         0         0         0
   Files :   26334     26334         0         0         0         0
   Bytes : 822.70 m  822.70 m         0         0         0         0
```

**Robocopy exited 1, which is success** — its exit status is a bitmask where 1
means "files were copied" and only >= 8 is failure. The PowerShell tool surfaced
that as "Exit code 1 / error". Anything wrapping this in a script must not test
`rc -eq 0`. (Same family of trap as the `enrich` stage exiting 0 having failed
47% of its work — the exit code and the truth are unrelated in both directions.)

`822.70 m` is MiB of real bytes; `du -sm` reports 885 because it rounds each of
26,334 files up to a 4 KB cluster. Not a shortfall — `FAILED 0` and the hash
manifest below settle it.

## 14:22 — FAILED ATTEMPT (no changes made): `sha256sum` manifest

`find … | xargs -0 sha256sum` died partway with `xargs: sha256sum: Permission
denied`, twice, after emitting 962 and 2,250 of 26,334 lines. Batching with
`-n 200` still truncated (1,401 of 6,248 on one directory alone). Spawning the
binary tens of thousands of times is what fails, not the hashing.

**This is the dangerous shape of failure**: it exits without an obvious error and
leaves a manifest that *looks* complete. A line count against the expected file
count is what caught it. Any future verification must assert the manifest line
count, never just diff two manifests — two equally-truncated manifests diff clean.
